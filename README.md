# Marigold (installable web app)

Upload this whole folder to any HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages).
Open the URL on your phone, then:
- Android (Chrome): tap **Install app** on the title screen, or the menu ⋮ → Install app.
- iPhone (Safari): Share → **Add to Home Screen**.

It runs full screen, works offline after the first load, and saves your progress on the device.
